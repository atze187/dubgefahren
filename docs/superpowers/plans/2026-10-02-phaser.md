# Phaser auf den Delay-Rückläufern Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ein sanfter 4-Stufen-Phaser (Phase-90-Charakter, freier Sweep in Hz) liegt nur auf den Delay-Rückläufern; drei Parameter (Rate, Depth, Mix, Standard-Mix 0) sind im Plugin automatierbar und über eine vorübergehende Regler-Gruppe PHASER im `FxPanel` bedienbar.

**Architecture:** Neue Klasse `Phaser` (`engine/Phaser.h/.cpp`): vier Allpässe 1. Ordnung, LFO-moduliert, weiches Feedback, 50/50-Mischung. `FxChain` besitzt eine Instanz und lässt sie die Delay-Rückläufer `dl`/`dr` bearbeiten, bevor diese mit `delayMix` in den Send gemischt werden. `FxParams` und `ParameterLayout` bekommen drei Parameter, das `FxPanel` eine Gruppe PHASER, die Editor-Basisbreite wächst von 1000 auf 1200 px.

**Tech Stack:** C++20, JUCE (Plugin-Teil), Catch2 (`DubgefahrenTests`, `DubgefahrenPluginTests`), CMake über `build.ps1`.

**Spec:** `docs/superpowers/specs/2026-10-02-phaser-design.md`

## Global Constraints

- Schnittstelle: `void Phaser::prepare(double sampleRate)`, `void Phaser::reset()`, `void Phaser::setParams(float rateHz, float depth, float mix)`, `void Phaser::process(float& l, float& r)` (in place).
- Parameterbereiche und Standardwerte: Rate 0,05 bis 3 Hz (Standard 0,4), Depth 0 bis 1 (Standard 0,5), Mix 0 bis 1 (Standard **0**).
- Vier Allpässe 1. Ordnung, gleiche Grenzfrequenz `fc`, `a = (tan(π·fc/sr) − 1) / (tan(π·fc/sr) + 1)`; Sweep um 700 Hz mit Breite `±(0,5 + 2,0·depth)` Oktaven, Sinus-LFO, rechter Kanal 90° versetzt.
- Mischung `y = (1 − 0,5·mix)·in + 0,5·mix·ap`; bei `mix` unter `1e-6` bit-genau `in`.
- Feedback `fb = 0,15 + 0,35·depth` über `tanh`, aus dem Ausgang des letzten Allpasses.
- Der Phaser wirkt nur auf die Delay-Rückläufer; Main-Bus und Send-Eingang bleiben unberührt.
- Alle Klangkonstanten stehen als benannte Werte oben in `Phaser.cpp`.
- Nicht enthalten: Tempo-Sync, 8 Stufen, Typ-Umschaltung, Grit-Knob, Advanced-Bereich.
- Die Basis dieses Branches ist `main` (ohne die offenen PRs #22, #23, #24); die Pfade und Zeilen dieses Plans beziehen sich auf diesen Stand.
- Build und Test: `powershell -ExecutionPolicy Bypass -File build.ps1 test`. Nur Engine-Tests: `powershell -ExecutionPolicy Bypass -File build.ps1 build`, danach `build\tests\Release\DubgefahrenTests.exe "[phaser]"` (Plugin-Tests: `build\tests\DubgefahrenPluginTests_artefacts\Release\DubgefahrenPluginTests.exe`).
- Commit-Messages enden mit der Zeile `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

1. `mix = 0` bleibt bit-genau durchgereicht, auch nachdem der Mix auf 1 und wieder zurückgeregelt wurde (der Glätter erreicht nie exakt 0) (Task 1 und 2).
2. Extreme und ungültige Parameter (Rate 100 oder −1, Depth und Mix außerhalb 0 bis 1) werden begrenzt; Rate 3 Hz bei Depth 1 bleibt stabil (Task 1).
3. Abtastraten 44,1, 96 und 192 kHz: `fc` bleibt unter Nyquist, Koeffizienten bleiben endlich, kein Eigenschwingen (Task 1).
4. NaN im Send-Eingang: `FxChain` setzt zurück, der Phaser-Zustand wird mit zurückgesetzt, danach läuft die Kette sauber weiter (Task 2).
5. Ein Plugin-Zustand ohne die neuen Parameter (alte Projekte) lädt mit Mix 0, also ohne Klangänderung (Task 3).

`engine/Phaser.h`:

```cpp
#pragma once
#include <array>

namespace dg {

// Sanfter 4-Stufen-Phaser (Phase-90-Charakter) für die Delay-Rückläufer: vier Allpässe 1. Ordnung mit
// LFO-modulierter Grenzfrequenz, weichem Feedback und 50/50-Mischung. Bei mix unter 1e-6 wird das Signal
// bit-genau durchgereicht. depth und mix werden vom Aufrufer geglättet.
class Phaser
{
public:
    void prepare(double sampleRate);
    void reset();
    void setParams(float rateHz, float depth, float mix);
    void process(float& l, float& r); // in place

private:
    struct Channel
    {
        std::array<float, 4> z {}; // Allpass-Zustände
        float fb = 0.0f;           // letzter Ausgang der Kette (für das Feedback)
    };

    float run(Channel& c, float x, float lfo) const;

    double sampleRate_ = 44100.0;
    double phase_ = 0.0; // LFO-Phase 0..1
    float rateHz_ = 0.4f;
    float depth_ = 0.5f;
    float mix_ = 0.0f;
    std::array<Channel, 2> ch_ {};
};

} // namespace dg
```

`engine/Phaser.cpp`:

```cpp
#include "engine/Phaser.h"
#include <algorithm>
#include <cmath>
#include "engine/DspMath.h"

namespace dg {

namespace {
// Klangkonstanten. Hier nachjustieren, nicht im Code verteilt.
constexpr float kCenterHz = 700.0f;       // Mitte des Sweeps
constexpr float kWidthMinOct = 0.5f;      // Sweep-Breite bei depth 0 (± Oktaven)
constexpr float kWidthDepthOct = 2.0f;    // zusätzliche Breite bei depth 1
constexpr float kFeedbackMin = 0.15f;
constexpr float kFeedbackDepth = 0.35f;
constexpr double kRightPhase = 0.25;      // 90° Versatz des rechten Kanals (in Perioden)
constexpr float kMinRateHz = 0.05f;
constexpr float kMaxRateHz = 3.0f;
constexpr float kMixOff = 1.0e-6f;
constexpr float kMinHz = 20.0f;
constexpr float kMaxNyquistFraction = 0.45f;
} // namespace

void Phaser::prepare(double sampleRate)
{
    sampleRate_ = sampleRate;
    reset();
}

void Phaser::reset()
{
    ch_.fill(Channel {});
    phase_ = 0.0;
}

void Phaser::setParams(float rateHz, float depth, float mix)
{
    rateHz_ = std::clamp(rateHz, kMinRateHz, kMaxRateHz);
    depth_ = std::clamp(depth, 0.0f, 1.0f);
    mix_ = std::clamp(mix, 0.0f, 1.0f);
}

float Phaser::run(Channel& c, float x, float lfo) const
{
    const float sr = static_cast<float>(sampleRate_);
    const float fc = std::clamp(kCenterHz * std::exp2((kWidthMinOct + kWidthDepthOct * depth_) * lfo), kMinHz,
                                kMaxNyquistFraction * sr);
    const float t = std::tan(kPi * fc / sr);
    const float a = (t - 1.0f) / (t + 1.0f);
    const float fb = kFeedbackMin + kFeedbackDepth * depth_;

    float v = x + fb * std::tanh(c.fb);
    for (auto& z : c.z)
    {
        const float y = a * v + z; // Allpass 1. Ordnung (transponierte Direktform II)
        z = v - a * y;
        v = y;
    }
    c.fb = v;
    return v;
}

void Phaser::process(float& l, float& r)
{
    const float lfoL = std::sin(kTwoPi * static_cast<float>(phase_));
    const float lfoR = std::sin(kTwoPi * static_cast<float>(phase_ + kRightPhase));
    phase_ += static_cast<double>(rateHz_) / sampleRate_;
    if (phase_ >= 1.0)
        phase_ -= 1.0;

    const float apL = run(ch_[0], l, lfoL);
    const float apR = run(ch_[1], r, lfoR);
    if (mix_ < kMixOff)
        return; // bit-genau durchgereicht
    const float dry = 1.0f - 0.5f * mix_;
    const float wet = 0.5f * mix_;
    l = dry * l + wet * apL;
    r = dry * r + wet * apR;
}

} // namespace dg
```
